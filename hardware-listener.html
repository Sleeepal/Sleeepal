独立取证听诊器

接上 USB 电源或充电宝，在现场把原音录进证据卡。结束后用手机回放标记片段、分析并生成报告。

01 · 硬件方案

采集和保存都在盒子里

  1. 接触探头贴墙或贴地，信号经前级送入 USB 声卡 Line-in。
  2. 独立主控Pi Zero 2 W 通过 OTG 接带供电的 USB Hub。RTC 保持采集时间。
  3. 证据卡主控把原音、时间、标记和质量日志写进可取出的卡。系统卡留在主板。
  4. 手机取证宝用读卡器导入兼容短包，核对原音后按标记回听。长录选择性导入待验证。

首台用一只已确认接线的接触探头，预留第二通道。目标原件格式为 48 kHz、16-bit PCM WAV，双声道每 5 分钟约 57.6 MB，24 小时约 16.59 GB。128 GB 证据卡和主板系统卡分开选型。接触通道采用相对电平，用于定位事件，定量声压与结构振动各有独立测量和标定流程。

电源选标明可持续输出 5 V / 3 A 的 USB 电源或充电宝，台架用 USB 电流表确认主机、Hub、声卡和写卡时的峰值。Pi 的电源口与 OTG 口分开接，Hub 须具备上游回灌隔离。面板 USB-C 作为 5 V 供电入口，内侧转接到主控电源口。模块未量尺寸时先在开敞台架上试接。

续航估算按铭牌 Wh × 0.80–0.90 ÷ 实测平均功率。以 10,000 mAh／37 Wh 为例，平均 2–3 W 时约 10–17 小时。20,000 mAh／74 Wh 约 20–33 小时。功耗、转换效率、充电宝自动关机和掉电尾段均需实测。24 小时验收先用稳定 USB 电源。

03 · 简易组装说明

先通电录一分钟，再装入外壳

  1. 备料和试配

    准备主控、系统 microSD、带供电 USB Hub、USB 声卡、USB 读卡器和证据卡。底壳开口向上打印，顶盖外观面朝下，背板平放。先用空白背板比对 USB-C、探头和卡座的实际尺寸，试装 M2.5 螺钉、绝缘柱和线缆固定夹。保留插拔和线束弯折空间。

  2. 断电接线

    探头接匹配的前级，前级输出接声卡的 LINE-IN。Pi 的 USB OTG 接 Hub 上游，声卡和证据卡读卡器接 Hub 下游。充电宝或 USB 电源分别给 Pi 的 PWR IN 和有供电隔离的 Hub 供电。采用成品线，确保 Hub 上游不会把电压送回 Pi。

  3. 装按键和对时模块

    候选引脚采用 BCM 编号。录制键 GPIO17、标记键 GPIO27，按下接 GND，输入启用上拉。录制、存储、故障灯分别用 GPIO22、23、24，各串约 1 kΩ 后接灯和地。RTC 用 3.3 V 兼容、无充电电路的模块，SDA 接 GPIO2，SCL 接 GPIO3，共地。以模块标注核对电平和接头，确认 RTC 正常读时后记录采集时区。

  4. 装系统并做台架短录

    用 Raspberry Pi Imager 在系统卡写入 Raspberry Pi OS Lite。首次可用另一台设备做配置。插入独立证据卡，确认它的挂载位置。用 ALSA 查声卡和实际支持的通道，再做一分钟 WAV 验证。每次只激励一路，回放核对声道和噪声。

  5. 安装采集服务后验证脱机

    工程固件需实现上电自检、长按开始／停止、独立标记、分段 WAV、SHA-256、UTC／帧锚和缺口日志。装入服务后断开调试连接，长按录制键开始，点标记键记事件，停止后等待存储灯提示卸载完成，再取卡。当前可先验证接线和原音。按键封存及兼容包导出需待独立采集服务通过实机测试。

  6. 挂装、验电源并导入

    主机和充电宝可放同一带固定带的袋中，两件分别固定。线缆留松弛段并做应力释放，避免 USB 插头承重。先试录并检查温升、掉电和充电宝自动关机。取卡后在手机「记录 → 听诊器录音 → 导入录音」选择兼容封存短包，确认时区、标记与回放。

台架命令示例。把命令中的声卡名和证据卡路径改成机器实际值。

arecord -l
lsblk -o NAME,LABEL,SIZE,MOUNTPOINTS
# 确认 /mnt/evidence 是证据卡挂载点
mountpoint -q /mnt/evidence && \
  arecord -D 'hw:CARD=Device,DEV=0' -f S16_LE -r 48000 -c 2 -t wav -d 60 \
  "/mnt/evidence/bench-$(date -u +%Y%m%dT%H%M%SZ).wav"
sync

此命令用于验证声卡、录音和写卡。正式取证短包另需设备与会话元数据、分段帧范围、质量日志和原件哈希。可以用浏览器的打印功能保存或打印本说明。
