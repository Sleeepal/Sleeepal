隐私说明 · 更新于 2026-07-25
01

录音零上传

实时麦克风分析、反相计算、声景排除和夜间事件判断在本机完成。麦克风原始音频、整夜录音、事件片段、导入录音以及可恢复语音内容的音频数据不会上传到 SleeePal、模型提供商、分析服务或其他远程服务。

02

可能保存在本机的内容

  • 桌面应用可能在应用支持目录生成本地夜报、事件时间、时长和强弱等结构化记录。
  • 音频片段只会在对应功能明确开启后保存在本机；反馈、账号、同步和家庭共享均不接收录音。
  • 只有你在官网反馈页主动下载或复制时，才会生成由你管理的反馈 JSON。
03

本地导出与反馈

SleeePal 反馈包不包含也不接收录音。截图、夜报和经检查的非录音诊断信息只有在你主动选择后才会进入反馈内容。你可以在本机回放、删除或导出自己的录音；导出后使用操作系统或第三方工具移动文件，是你在 SleeePal 产品链路之外的独立操作。

04

梦想卡与钱包账号

  • 梦想草稿和本机对话默认保存在当前浏览器；连接钱包本身不会上传内容。
  • 钱包登录只验证你对地址的控制权，不读取余额、NFT、交易记录、助记词或私钥，也不要求链上交易。
  • 你可以主动签名绑定第二个恢复钱包；它会指向同一个睡眠宝账号和同一组梦想。用恢复钱包登录并重新签名后，可以把它设为主钱包，再移除失联旧钱包并撤销旧会话。已属于另一账号的钱包不会被自动合并，主钱包和当前会话身份也不能被误删。
  • 只有你在合并预览中确认后，当前梦卡的目标、阶段、成功标准和边界才会保存到 SleeePal 账号数据库；本机对话不会随梦卡自动上传。
05

可选 AI 对话

AI 模式必须单独开启。每次发送会把当前账号梦卡、这条新消息和最近 8 条账号 AI 对话经 SleeePal 服务端发送给 OpenAI；浏览器中的本机历史不会自动加入。账号数据库会保存你主动发送的账号对话、模型回复、同意记录、梦卡建议、授权决定、你生成的 Markdown 或 HTML 产物版本和必要的运行审计。

模型请求显式设置 store:false，用于关闭 Responses API 的应用状态存储；这不等同于 OpenAI 组织级“零数据保留（ZDR）”。请不要在早期 Beta 中提交密码、私钥、助记词、支付凭据、未脱敏的健康资料或其他不应交给远程模型的秘密。

“美梦成真”与睡眠音频运行时彼此独立。AI 对话只接收你在该模块主动提交的内容，不接收麦克风音频、睡眠录音或事件片段。

06

保留与删除

浏览器梦想可以逐个删除或导出。“美梦成真”账号管理中也提供完整 JSON 备份，包含账号梦卡、AI 对话、建议、授权、任务证据和 Markdown/HTML 产物正文；备份文件由你自行保管。梦想行动台下载后把勾选与笔记默认留在打开它的浏览器，也可由你导出独立进度 JSON；这些下载后的本机数据不会自动回传账号。彻底删除账号需要再次勾选不可恢复提示并输入确认短语，完成后会删除服务器中的钱包身份、会话和全部账号内容。本机浏览器里的梦想与已下载文件不会随服务器账号一起删除，仍需由你单独清理。

桌面应用可能把报告或经你选择的片段留在本机；这些本机文件从不上传，也不属于网页账号删除范围。线上账号数据的保留期限、备份周期和删除响应方式会在对应功能开放时明确说明。

07

当前边界

录音零上传是持续有效的产品承诺，不会被未来的云同步、家庭共享、远程诊断、反馈、AI 功能或账号开关覆盖。“美梦成真”的钱包账号与 AI 服务处于独立早期验证阶段；AI 当前没有工具和执行器，梦卡建议不会自动生效，授权卡也不会触发发布、发送、购买、删除或连接外部服务。
