02 · 日常坐姿 看屏幕办公 · 参考 10%～20%

正常办公距离仍可尝试削弱部分持续低频，适合办公室、咖啡厅和交通途中。

03 · 外层边界 距离较远 · 参考约 5%

作用继续递减，体感可能不明显；这层主要明确个人静谧空间不是整间房静音。

MAC 测试流程

SleeePal for macOS

Mac 版继续进行签名、公证和实机检查。已经安装测试版的用户可以直接打开。

查看 Mac 测试进展 打开已安装版本
  1. 01
    下载 DMG

    只使用 SleeePal 官方测试任务提供的包。

  2. 02
    拖入“应用程序”

    首次打开时按系统提示确认测试来源。

  3. 03
    允许麦克风

    在“系统设置 → 隐私与安全性 → 麦克风”中允许。

  4. 04
    刷新设备

    MacBook 内置 Mic 与扬声器识别后，无需外设。

WINDOWS X64 内测

SleeePal for Windows

Windows 版会在独立 Windows 主机构建并运行无界面自检。测试包暂未签名，不作为公开正式版。

获取 Windows 内测包 打开已安装版本
  1. 01
    下载 QA ZIP

    在最新测试任务中下载 sleeepal-windows-x64-qa。

  2. 02
    完整解压

    不要在压缩包预览窗口里直接运行安装程序。

  3. 03
    双击 Install-SleeePal.cmd

    安装到当前用户目录，不需要管理员权限。

  4. 04
    允许麦克风并刷新

    Windows 笔记本的 Microphone Array 与 Speakers 会优先自动选中。
